# Khushboo Singh — Research & AI Portfolio

Responsive, dark-themed personal portfolio based on the uploaded resume and public LinkedIn profile. It presents psychology, AI, research methods, and cognitive neuroscience interests.

## Project Architecture
- `index.html` — Portfolio structure, semantic content, and interactive canvas mounts
- `styles.css` & `portfolio-additions.css` — Editorial typography, layout grid, dark-theme styling, and responsive rules
- `photo-particle-engine.js` & `khushboo_particle_data.js` — Interactive 3D WebGL point-cloud portrait hero
- `neural-brain.js` & `brain_frames_data.js` — 3D neural brain rotation and synaptic glow engine
- `energy-orb.js` — Procedural WebGL energy orb with interactive mouse gravity
- `radar-scanner.js` — Multi-channel cybernetic radar scanners with telemetry tracking
- `ripples-mesh.js` & `three.min.js` — Ambient WebGL background dynamics and Three.js runtime
- `resume.pdf` — Curriculum vitae and credentials
- `images/khushboo-signal.png` — High-resolution portrait visual asset

## Run locally
Extract the ZIP and open `index.html` in a modern browser. No build step or framework is required. Internet access is needed for the Google Fonts used by the design; the page still works without them.
